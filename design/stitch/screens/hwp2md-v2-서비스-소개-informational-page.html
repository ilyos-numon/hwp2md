문서 내용을 다시 활용하기 어려우셨나요?

한글(HWP/HWPX) 문서 안의 텍스트, 표, 이미지를 마크다운 기반의 협업 도구나 지식 관리 시스템으로 옮기려면 일일이 복사하고 서식을 다시 다듬는 번거로운 반복 작업이 필요했습니다. hwp2md는 이러한 반복 작업을 덜어내고 문서 내용을 빠르게 재활용할 수 있도록 돕습니다.

작동 원리

간단한 3단계로 변환하세요

복잡한 설정이나 설치 없이 바로 사용할 수 있는 간단한 워크플로우를 제공합니다.

1

파일 선택

HWP 또는 HWPX 문서를 선택하세요.

2

결과 확인

변환된 Markdown을 미리보기와 원문으로 확인하세요.

3

다운로드

Markdown과 추출된 이미지가 포함된 ZIP을 받으세요.

핵심 기능

문서 재활용에 필요한 핵심을 담았습니다

불필요한 기능은 덜어내고, 마크다운 변환과 콘텐츠 추출에 집중했습니다.

HWP 5.0 / HWPX 지원

기존 바이너리 HWP 5.0 포맷과 최신 XML 기반 HWPX 표준 문서를 모두 지원합니다.

텍스트와 제목 구조 변환

문서 내 문단 텍스트와 제목 수준(Header) 계층 구조를 마크다운 서식으로 변환합니다.

표와 추출 이미지 처리

문서 내 테이블 구조를 마크다운 표로 파싱하며, 포함된 이미지 파일을 추출합니다.

미리보기 및 원문 동시 확인

서식 렌더링 결과와 순수 Markdown 원문 코드를 양면 패널에서 나란히 검토할 수 있습니다.

ZIP 패키지 다운로드

Markdown 문서와 함께 추출된 원본 이미지들이 정리된 압축 파일로 제공됩니다.

두 가지 처리 모드

작업 환경이나 보안 정책에 따라 빠른 서버 모드 또는 브라우저 로컬 모드를 선택할 수 있습니다.

실용적인 가치

왜 hwp2md를 사용해야 할까요?

불필요한 과장 없이, 실제 작업 과정에서 바로 체감할 수 있는 실질적인 편리함을 제공합니다.

다운로드 전 즉시 결과 확인

파일을 다운로드하기 전에 브라우저 화면에서 서식 렌더링과 마크다운 본문을 바로 눈으로 확인하고 검증할 수 있습니다.

생성된 마크다운 간편 복사 및 재활용

전체 파일을 다운로드하지 않아도 우측 원문 패널의 복사 버튼으로 필요한 텍스트를 클립보드에 바로 담아 활용할 수 있습니다.

추출 이미지 파일 패키지 보존

문서 안에 포함된 주요 이미지를 별도의 수작업 캡처 없이 정돈된 파일 형태로 마크다운과 함께 묶어 내려받을 수 있습니다.

사용 환경에 맞춘 유연한 처리 모드

속도가 중요한 일반적인 변환은 서버 모드로, 파일 전송이 민감한 내부 문서 등은 브라우저 처리 모드로 선택할 수 있습니다.

개인정보 및 보안

문서 처리와 보안 정책

hwp2md는 사용자의 문서를 보관하거나 무단으로 활용하지 않으며, 두 가지 안전한 처리 방식을 투명하게 안내합니다.

서버 모드 (기본)

디스크 비저장 메모리 처리

서버 모드에서는 파일을 디스크에 저장하지 않고 메모리에서 처리합니다.

변환 요청 시 전송된 파일 바이트는 변환 작업 수행 즉시 메모리에서 해제되며, 서버 저장소에 어떠한 문서 기록이나 데이터베이스 사본도 남기지 않습니다.

* 변환 과정에서 일반적인 웹 통신을 사용합니다.
브라우저 처리 모드

문서 파일 서버 전송 없음

브라우저 모드에서는 문서 파일 자체를 서버로 전송하지 않고 처리합니다.

문서 파싱 및 변환 연산이 사용자의 브라우저 내 웹어셈블리(Wasm) 환경에서 직접 실행되므로, 원본 문서 바이너리가 외부 네트워크로 나가지 않습니다.

* 단, 브라우저 모드 초기화 시 hwp2md 서버로부터 약 20MB 상당의 실행 패키지 번들을 다운로드하는 네트워크 과정이 필요합니다.
변환 시 꼭 알아두실 점 (지원 한계)
  • 모든 원본 서식이 완벽하게 보존되는 것은 아닙니다.
  • 각주·미주, 목차 및 복합 목록 구조 등의 변환에는 한계가 있습니다.
  • 암호화되거나 배포용으로 보안 잠금된 HWP 5.0 문서는 지원되지 않습니다.
  • 안정적인 변환을 위해 지원되는 단일 파일 크기 제한은 50MB입니다.
