HWP to Markdown 변환 플랫폼

한글 문서(HWP/HWPX)를 깔끔한 마크다운으로

공공기관, 교육기관, 연구소의 HWP 문서를 표준 웹 마크다운 문서로 즉시 변환하여 Notion, Obsidian, GitHub 등에서 바로 활용하세요.

변환 시작하기 어떻게 작동하나요

⚠️ 닫힌 문서 포맷에서 열린 마크다운으로

HWP 형식은 한국 공공 및 업무 환경에서 폭넓게 쓰이지만, 현대적인 협업 툴(GitHub, Notion, GitBook, LLM 프롬프트 등)과의 상호운용성이 낮습니다. hwp2md는 복잡한 서식, 표, 각주, 본문 계층을 손실 없이 경량 Markdown 문법으로 변환하여 기술 문서화 및 디지털 자산화를 돕습니다.

작동 원리 (How it works)

01. 파싱

바이너리 스트림 분석

HWP 5.0 복합 OLE 및 HWPX XML 포맷의 구조를 정밀하게 파싱하여 문단, 표, 그림 정보를 추출합니다.

02. 매핑

문서 의미 체계 보존

제목(Heading), 목록, 굵게/기울임, 다단 표를 표준 CommonMark / GFM 규격으로 정규화합니다.

03. 다운로드

실시간 미리보기 & ZIP

변환된 서식을 실시간 확인하고 원문 복사 또는 삽입된 이미지 번들이 포함된 ZIP으로 내려받습니다.

핵심 기능 (Key Features)

표(Table) 완전 지원

복잡한 셀 병합 및 정렬 데이터를 마크다운 파이프 테이블로 안전하게 정리합니다.

이미지 자동 패키징

문서 내 포함된 삽입 이미지를 자동으로 추출하여 상대경로 링크와 함께 ZIP으로 묶어줍니다.

이중 변환 엔진

고속 대용량 처리를 위한 서버 모드와 보안 문서를 위한 클라이언트 브라우저 모드를 자유롭게 전환합니다.

다크 모드 & 실시간 복사

작업 환경에 맞춘 유려한 다크 모드와 1-클릭 클립보드 복사 편의성을 제공합니다.

왜 hwp2md인가요?

별도의 한글 오피스 설치나 액티브X 없이, 최신 웹 브라우저만으로 HWP/HWPX 문서를 처리할 수 있습니다. LLM(대형 언어 모델)에 문서를 학습시키거나 RAG(검색 증강 생성) 파이프라인에 한글 문서를 투입할 때 가장 신뢰할 수 있는 텍스트 전처리 엔진입니다.

개인정보 및 보안 안내 (Privacy)

서버 모드

변환 요청 즉시 메모리 상에서 처리된 후 파일 저장이 일체 발생하지 않으며, 작업 완료 즉시 파기됩니다.

브라우저 모드 (WebAssembly)

문서 파일이 외부 서버로 전혀 전송되지 않고 사용자의 로컬 브라우저 내부에서 100% 안전하게 변환됩니다.

지원 제한 사항 (Limitations)

  • 암호(배포용 비밀번호)가 걸려 있는 문서는 사전에 암호 해제가 필요합니다.
  • 복합 수식 개체 및 OLE 포함 차트는 텍스트 또는 이미지로 대체 추출될 수 있습니다.
  • 문서 1개당 최대 권장 용량은 50MB입니다.

기술 지원 및 오픈소스

버그 제보나 기능 건의사항은 프로젝트 이슈 트래커를 이용해 주세요.
