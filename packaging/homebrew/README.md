# homebrew-tap

Homebrew tap for [hwp2md](https://github.com/ilyos-numon/hwp2md), a converter from Korean HWP, HWPX and HWPML documents to Markdown.

```sh
brew install ilyos-numon/tap/hwp2md
hwp2md --version
```

- The formula installs the prebuilt single-file executable from the hwp2md GitHub Release (macOS arm64/x64, Linux x64).
- `Formula/hwp2md.rb` is generated by `scripts/update_formula.py` in the hwp2md repository. Do not edit it by hand; report issues at https://github.com/ilyos-numon/hwp2md/issues.
- License: MIT, same as hwp2md.

## 한국어

한글(HWP·HWPX·HWPML) 문서를 Markdown 으로 바꾸는 [hwp2md](https://github.com/ilyos-numon/hwp2md) 의 Homebrew 탭입니다.

- 설치: `brew install ilyos-numon/tap/hwp2md`
- formula 는 hwp2md GitHub Release 의 단일 실행 파일(macOS arm64/x64, Linux x64)을 그대로 설치합니다.
- `Formula/hwp2md.rb` 는 hwp2md 저장소의 `scripts/update_formula.py` 가 만든 생성물입니다. 직접 고치지 말고 원 저장소에 이슈를 남겨 주세요.
- 라이선스: MIT (hwp2md 와 같음).
