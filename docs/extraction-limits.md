# 추출 한계: 끝내 꺼내지 못하는 것과 그 이유

> 이 문서는 hwp2md 가 **최대한 노력했지만 Markdown 으로 꺼내지 못하는 요소**를 이유·대안과 함께 적는다. 독자는 이 도구를 쓰는 사람과 화면을 만드는 프론트엔드 개발자다.
> 기준은 현재 코드다(`src/hwp2md/`). 동작의 전체 명세는 [feature-reference.md](feature-reference.md) 에 있다.

## 1. 요약

- **새로 꺼내게 된 것**: 표 칸 안 그림, 글상자·도형·묶음 개체 안 글과 그림, 표·그림 캡션, 하이퍼링크, 각주·미주, 수식(LaTeX), 번호·글머리표 목록, OOXML 차트의 데이터 표, OLE 안 원본 그림, 배포용 문서, HWPML 2.x(.hml) 문서.
- **일부러 빼고 개수만 알려 주는 것**: 머리말·꼬리말, 메모, 숨은 설명. 본문이 아니거나 작성자 정보가 들어 있을 수 있어서다.
- **여전히 안 되는 것**: 비밀번호 문서, 문서보안(DRM) 파일, 구형 차트 데이터, WMF/EMF 그림 변환, 쪽 번호·날짜 같은 필드 값 재계산, 글자 서식, HWP 3.0 이하 문서.
- **근사로만 되는 것**: 목록 번호, 수식 LaTeX, 글상자 읽기 순서, 단락 중간 그림 위치(HWP 5.0 과 HWPX·HWPML 이 다르다).
- 꺼내지 못한 요소는 조용히 사라지지 않는다. 9가지 "건너뜀 종류"로 세어 CLI·API·화면에 개수로 보여 준다(§4).

## 2. 요소별 상태

상태 뜻: **추출** = Markdown 에 나온다 · **부분** = 나오지만 근사이거나 일부만 나온다 · **불가** = 꺼내지 못한다 · **제외** = 꺼낼 수 있지만 일부러 내보내지 않는다.
"건너뜀 종류"는 API `skipped[].kind` 값과 화면·CLI 에 보이는 라벨이다. 빈 칸이면 보고하지 않는다.

### 2.1 건너뜀으로 보고되는 요소 (9종)

| 요소 | 상태(추출·부분·불가·제외) | 이유 | 대안·우회 | 건너뜀 종류 |
|---|---|---|---|---|
| 머리말·꼬리말 | 제외 | 쪽마다 반복되는 장식이라 본문이 아니다. 안의 글·표·그림까지 통째로 건너뛴다. 세 포맷이 같게 동작한다 | 필요한 글은 한글에서 본문으로 복사한 뒤 변환한다 | `header_footer` · 머리말·꼬리말 |
| 메모 | 제외 | 작성자 이름 같은 개인정보가 들어 있을 수 있다(개인정보 최소 수집 원칙). HWP 5.0·HWPX 만 센다. HWPML 은 세지 않는다 | 메모 내용이 필요하면 한글에서 본문으로 옮긴다 | `memo` · 메모 |
| 숨은 설명 | 제외 | 메모와 같은 이유. 화면에 보이지 않는 글이다 | 같음 | `hidden_comment` · 숨은 설명 |
| 구형 차트(데이터를 꺼낼 수 없는 차트) | 불가 | 구형 차트(`Contents` 스트림)는 공개 문서가 없는 객체 직렬화 형식이라 수십 종 객체를 해석해야 한다. HWPX 차트 XML 에 계열이 없을 때도 여기로 센다 | 한글에서 차트를 선택해 그림으로 복사·붙여넣기한 뒤 저장하면 그림으로 나온다 | `chart_legacy` · 데이터를 꺼낼 수 없는 차트 |
| OLE 개체 (차트·그림이 아닌 것) | 부분 | OLE 안에 원본 PNG·JPEG·GIF·BMP(`Ole10Native`)가 있으면 그림으로 꺼낸다. 엑셀 표·다른 프로그램 개체 등 그 밖은 꺼내지 않는다. 미리보기 그림(`OlePres000`)도 꺼내지 않는다 | 원본 프로그램에서 표·그림으로 다시 붙여넣는다 | `ole` · OLE 개체 |
| 글맵시 | 불가 | 장식 글자 개체. 실제 샘플이 없어 합성 문서로만 확인했다 | 일반 글자로 바꿔 저장한다 | `textart` · 글맵시 |
| 양식 개체 (단추·체크박스·입력란 등) | 불가 | 입력 위젯이라 Markdown 대응이 없다. HWP 5.0 리더는 세지 않는다(HWPX·HWPML 만). 실제 샘플 없음 | 필요한 값은 일반 글자로 바꿔 저장한다 | `form_control` · 양식 개체 |
| 외부 연결 그림 | 불가 | 그림 본체가 문서 밖 파일 경로를 가리킨다. 그 파일은 변환하는 쪽에 없다. HWP 5.0·HWPML 만 구분해 센다(HWPX 는 본체 없는 그림으로 센다) | 한글에서 "그림 넣기"로 문서에 포함해 저장한다 | `image_link` · 외부 연결 그림 |
| 본체 없는 그림 | 불가 | 그림 참조는 있는데 문서 안에 바이트가 없거나 깨졌다 | 원본에서 그림을 다시 넣는다 | `image_missing` · 본체 없는 그림 |

세는 단위: 머리말·꼬리말·메모·숨은 설명·차트·OLE·글맵시·양식 개체는 요소 1개당 1, 그림은 참조 1개당 1. 머리말 안의 그림·표는 따로 세지 않는다.

### 2.2 문서 단위로 거부하거나 받지 않는 입력

| 요소 | 상태(추출·부분·불가·제외) | 이유 | 대안·우회 | 건너뜀 종류 |
|---|---|---|---|---|
| 비밀번호 문서 (HWP 5.0 암호 비트, HWPX `encryption-data`) | 불가 | 열쇠가 비밀번호에서 만들어지고 알고리즘이 공개돼 있지 않다. 비밀번호 입력·추측은 범위 밖이다. 오류 코드 `encrypted` 로 정확히 알려 준다 | 한글에서 암호를 해제하고 다시 저장한 뒤 변환한다 | (오류 `encrypted`) |
| 문서보안(DRM) 파일 (기업용 DRM 래핑, HWP 5.0 DRM 비트) | 불가 | 파일 전체가 암호화돼 있고 열쇠는 DRM 서버·에이전트에 있다. 공개 형식이 없다. 해제·우회는 하지 않는다. 오류 코드 `drm` | 사내 보안 프로그램에서 DRM 을 해제(반출 승인)한 파일로 변환한다 | (오류 `drm`) |
| 배포용 문서 (복사·인쇄 제한) | 추출 | 한컴 공개 문서의 절차(AES-128)로 순수 파이썬 복호화한다. 작성자가 복사를 제한한 문서이므로 쓰임새는 사용자가 판단한다 | — | — |
| HWPML 2.x (.hml, 한글 XML 문서) | 추출 | 세 번째 입력 포맷. 리터럴 내부 엔티티만 허용하고 50MB 상한 | — | — |
| HWP 3.0 이하 | 불가 | 형식이 HWP 5.0 과 전혀 다르다. `not_hwp` 로 거부한다 | 한글에서 열어 HWP 5.0(.hwp) 또는 HWPX 로 다른 이름으로 저장한다 | (오류 `not_hwp`) |
| HWPML 의 실제 샘플 미검증 요소 (캡션·글상자·OLE 위치, 각주·수식·링크·목록) | 부분 | 코드와 합성 문서로는 HWPX 와 같은 결과를 확인했다. 실제 샘플 2개에는 이 요소들이 없어 실제 파일로는 확인하지 못했다. OLE 개체 위치는 HWPX 규칙(앵커 단락 뒤)으로 추정했다 | 결과가 이상하면 HWPX 로 다시 저장해 변환해 본다 | — |

### 2.3 출력이 근사이거나 꺼내지 않는 요소

| 요소 | 상태(추출·부분·불가·제외) | 이유 | 대안·우회 | 건너뜀 종류 |
|---|---|---|---|---|
| OOXML 차트 (`OOXMLChartContents`, HWPX `Chart/` XML) | 부분 | 차트에 저장된 캐시값으로 `차트: 제목` 단락 + 데이터 표를 만든다. 합성 문서로만 확인했다. 실제 샘플의 차트 1개는 OOXML 이 아니었다. 그래프 모양은 재현하지 않는다 | 그래프 모양이 필요하면 차트를 그림으로 붙여넣는다 | 실패 시 `chart_legacy` |
| WMF/EMF 그림 | 부분 | 원본 바이트 그대로 저장한다. 순수 파이썬 래스터화 구현이 없고 Pillow 는 Windows 에서만 읽는다. 브라우저 미리보기에서 안 보일 수 있다 | 한글에서 그림을 PNG 로 바꿔 넣거나, 저장된 파일을 그림 편집기로 변환한다 | — |
| BMP 그림 | 추출 | 원본 그대로 저장한다. 브라우저가 표시한다 | — | — |
| 필드 값 (쪽 번호·날짜·자동 번호) | 불가 | 문서에는 마지막으로 표시된 글자만 있거나 아예 없다. 쪽 번호는 쪽 나눔 계산(레이아웃 엔진) 없이는 알 수 없다. 누름틀 등 필드의 **표시 글자**는 본문에 남는다 | 한글에서 필드를 일반 글자로 고정한 뒤 저장한다 | — |
| 번호 목록의 번호 | 부분 | 번호는 문서 단위 카운터로 근사한다(같은 번호 정의·수준별 증가, 더 깊은 수준은 리셋). 새 번호 시작·구역 이어짐·개요 번호 혼합 규칙은 공개돼 있지 않다. 표 칸 안 목록은 머리 글자(`- `, `1. ` 등)만 칸 글자 앞에 붙인다 | 정확한 번호가 중요하면 한글에서 번호를 일반 글자로 바꿔 저장한다 | — |
| 수식 | 부분 | 한글 수식 스크립트를 토큰 치환 방식 변환기로 LaTeX(`$…$`, 단락에 수식만 있으면 `$$…$$`)로 바꾼다. 수식 문법 전 범위를 커버하지 못한다. 변환에 실패하면 원문 스크립트를 코드 스팬으로 남겨 내용은 잃지 않는다 | 결과 LaTeX 를 직접 다듬는다 | — |
| 글상자·묶음 개체 글의 읽기 순서 | 부분 | 저장 순서(자식 배열 순서)대로 내보낸다. 화면 위치(좌표)로 재정렬하려면 레이아웃 계산이 필요하다. 개체 내용은 앵커 단락 뒤에 온다 | 순서가 중요하면 글상자 글을 본문으로 옮긴다 | — |
| 단락 중간 그림 위치 | 부분 | "앞 [그림] 뒤" 한 단락이 HWP 5.0 에서는 `앞뒤` → 그림(그림이 단락 뒤), HWPX·HWPML 에서는 `앞` → 그림 → `뒤`(그림 위치에서 단락을 나눔)로 나온다. 맞추면 기존 출력과 단락 수가 넓게 바뀌어 이번에는 맞추지 않았다. 표도 같다 | 그림을 단독 단락에 두고 저장하면 두 포맷 결과가 같다 | — |
| 굵게·기울임·밑줄·글꼴·색·정렬 | 불가(범위 밖) | 이 도구는 구조(제목·표·목록·그림)만 옮긴다. "서식 완벽 재현"은 하지 않는 것으로 정했다 | 서식이 필요한 문서는 한글에서 PDF·DOCX 로 내보낸다 | — |
| 책갈피 | 제외 | 본문 내용이 없고 GFM 에는 표준 앵커 문법이 없다. 출력도 보고도 하지 않는다 | — | — |
| 메모 내용 | 제외 | 위 2.1 "메모" 와 같다. 개수만 보고한다 | — | (`memo`) |
| 표 병합 | 부분 | GFM 표는 병합을 표현하지 못한다. 병합으로 덮인 칸은 빈 칸, 첫 행은 늘 머리 행이다 | — | — |

## 4. 건너뜀이 보이는 곳

같은 값(`SkipCounter.items()`, 보고 순서는 위 2.1 표 순서)이 세 곳에 나온다.

- **CLI**: 변환 요약 뒤에 한 줄이 붙는다. 건너뜀이 없으면 줄이 없다.
  ```
  ✓ 문서.hwp → 문서.md
    단락 120개 · 표 3개
    건너뜀: 머리말·꼬리말 2개 · OLE 개체 1개
  ```
- **API** (`/api/convert` 성공 응답, 브라우저 모드도 같은 모양): `skipped` 배열. 항상 있고, 없으면 `[]`.
  ```json
  "skipped": [{"kind": "header_footer", "label": "머리말·꼬리말", "count": 2}]
  ```
  라이브러리에서는 `ConvertResult.skipped`, `MemoryResult.skipped` (`(kind, count)` 튜플).
- **웹 화면**: `#skipped`(`role="status"`) 영역에 `변환하지 못한 요소: 머리말·꼬리말 2개 · OLE 개체 1개 (자세한 이유: docs/extraction-limits.md)`. 건너뜀이 없으면 숨겨진다. 라벨은 응답의 `label` 을 그대로 `textContent` 로 쓴다.

보호 문서 오류는 건너뜀이 아니라 변환 실패다: CLI 종료 코드 3 과 `unsupported HWP file (DRM protected)` / `(password protected)`, API `drm`·`encrypted` (415), 화면은 해제 방법을 안내하는 문구.

## 5. 사용자 우회 방법 (일반)

1. **한글에서 다른 이름으로 저장**: HWP 3.0 이하·이상하게 나오는 문서는 한글에서 열어 HWP(5.0) 또는 HWPX 로 다시 저장한다.
2. **암호 해제**: 비밀번호 문서는 한글에서 암호를 지우고 저장한 뒤 변환한다.
3. **DRM 해제**: 문서보안 파일은 사내 보안 프로그램에서 해제(반출 승인)한 사본으로 변환한다.
4. **차트·OLE 를 그림으로**: 차트나 다른 프로그램 개체는 그림으로 복사해 붙여넣고 저장하면 그림으로 나온다.
5. **필드·번호를 글자로**: 쪽 번호·날짜·정확한 목록 번호가 필요하면 한글에서 일반 글자로 바꿔 저장한다.
6. **외부 연결 그림 포함**: 그림을 문서에 포함(연결 해제)해 저장한다.
