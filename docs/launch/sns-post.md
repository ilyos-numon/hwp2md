HWP 문서를 LLM이나 RAG에 넣을 때마다 변환에서 막혀서 hwp2md를 만들었습니다.

한컴오피스 없이 HWP 5.0·HWPX·HWPML 문서를 Markdown으로 바꿉니다. 제목 구조, 표, 그림, 각주, 수식(LaTeX)을 살려서 옮기고, 꺼내지 못한 요소는 개수로 알려 줍니다.

설치 없이 브라우저에서 써 볼 수 있습니다. 변환은 브라우저 안에서만 하고 파일은 기기 밖으로 나가지 않습니다. 첫 준비에 1분 정도 걸립니다.
https://ilyos-numon.github.io/hwp2md/

설치해서 쓰려면 pip install hwp2markdown, 명령은 hwp2md 입니다. 비밀번호·DRM 문서와 글자 서식은 지원하지 않습니다. MIT 라이선스입니다.

변환이 이상한 문서가 있으면 알려 주세요.
https://github.com/ilyos-numon/hwp2md
