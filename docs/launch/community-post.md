# 개발자 커뮤니티용 게시글 초안

## 제목 후보

1. 한컴오피스 없이 HWP를 Markdown으로 바꾸는 도구를 만들었습니다 (브라우저에서 바로 체험)
2. HWP·HWPX를 RAG에 넣기 전에 쓰려고 만든 변환기 hwp2md를 공개합니다
3. 파일을 서버에 올리지 않는 HWP → Markdown 변환기, 써 보시고 의견 부탁드립니다

## 본문

HWP 문서를 LLM이나 RAG 파이프라인에 넣으려다 매번 같은 곳에서 막혔습니다. 공공·기업 문서는 대부분 HWP나 HWPX인데, 이걸 텍스트로 꺼내려면 한컴오피스를 깔거나, 표와 그림이 다 흩어진 결과를 받아 손으로 고쳐야 했습니다. 제목 구조가 사라지니 청킹도 애매해지고, 표는 줄글로 뭉개졌습니다. 그래서 필요한 만큼만 직접 만들었습니다.

hwp2md는 HWP 문서를 Markdown으로 바꾸는 순수 파이썬 도구입니다. 한컴오피스 없이 동작하고, 의존성은 `olefile`과 `lxml` 두 개입니다.

### 무엇을 하나

- 입력: HWP 5.0, HWPX, HWPML(.hml), 배포용 문서(복사·인쇄 제한 문서)
- 문서의 개요 수준을 `#` 제목으로 옮겨서 제목 단위로 자르기 쉽게 했습니다.
- 표는 Markdown 표로, 그림은 파일로 꺼내 상대 경로로 링크합니다.
- 각주·미주, 수식(LaTeX), 하이퍼링크, 목록, 표·그림 캡션도 옮깁니다.
- 꺼내지 못한 요소는 조용히 버리지 않고 종류별 개수로 알려 줍니다. 머리말·꼬리말, 메모 같은 것들입니다.
- CLI, 파이썬 라이브러리, 로컬 웹 미리보기가 같은 엔진을 씁니다. 세 곳의 출력이 같은지 테스트로 확인합니다.

### 30초 데모

```bash
pip install hwp2markdown
hwp2md 문서.hwp -o out/
```

PyPI 배포 이름은 `hwp2markdown`이고, 설치 후 명령과 import 이름은 `hwp2md`입니다. PyPI의 `hwp2md`는 이름만 같은 다른 프로젝트라서 설치할 때만 주의해 주세요. Python 3.11 이상이 필요합니다.

코드에서 쓸 때는 이렇게 씁니다.

```python
from hwp2md import convert
```

### 설치 없이 브라우저에서

https://ilyos-numon.github.io/hwp2md/

"변환 도구 열기"를 누르고 파일을 끌어다 놓으면 왼쪽에 미리보기, 오른쪽에 Markdown 원문이 나옵니다. 결과는 zip으로 받을 수 있습니다. 브라우저 안에서 파이썬(Pyodide)을 띄우는 방식이라 첫 준비에 1분 정도 걸립니다. 그다음부터는 바로 변환됩니다.

### 파일은 기기 밖으로 나가지 않습니다

HWP 문서에는 내부 자료가 많아서 이 부분을 가장 신경 썼습니다.

- 브라우저 체험 페이지는 변환을 브라우저 안에서만 합니다. 파일 바이트를 어디에도 보내지 않습니다. 네트워크 요청은 Pyodide와 변환 코드를 내려받는 것뿐이고, 변환 중에 파일을 보내는 요청이 없는지 E2E 테스트로 확인합니다.
- 인터넷이 없는 환경이라면 `pip install 'hwp2markdown[web]'` 후 `hwp2md serve`로 로컬 웹 미리보기를 띄우면 됩니다. 화면 자원이 패키지에 들어 있어 인터넷 없이 동작하고, 업로드는 메모리에서만 변환하고 디스크에 쓰지 않습니다.
- 메모와 숨은 설명은 작성자 정보가 들어 있을 수 있어서 일부러 내보내지 않고 개수만 알려 줍니다.

### 아직 안 되는 것

솔직하게 적어 둡니다.

- 비밀번호 문서, 문서보안(DRM) 파일, HWP 3.0 이하 문서는 받지 않고 이유를 오류로 알려 줍니다. 암호 해제나 우회는 하지 않습니다.
- 글자 서식(굵게, 글꼴, 색)은 옮기지 않습니다. 구조만 옮기는 도구입니다.
- 구형 차트는 데이터를 꺼내지 못합니다. WMF/EMF 그림은 원본 그대로 저장해서 브라우저에서 안 보일 수 있습니다.
- 쪽 번호·날짜 같은 필드 값은 다시 계산하지 않고, 목록 번호와 수식 LaTeX는 근사입니다.
- 단락 중간에 놓인 그림 위치가 HWP 5.0과 HWPX에서 다르게 나올 수 있습니다.

요소별 전체 목록과 우회 방법은 저장소의 docs/extraction-limits.md에 정리해 두었습니다.

### 부탁드리는 것

혼자 만든 도구라 제가 가진 문서로만 확인했습니다. 변환이 이상하게 나오는 문서가 있으면 이슈로 알려 주세요. 원본 파일을 올리기 어려우면 어떤 요소(표, 그림, 목록 등)가 어떻게 틀렸는지만 적어 주셔도 큰 도움이 됩니다. 어떤 기능이 먼저 필요한지(제목 단위 분할, 폴더 일괄 변환, 병합 셀 보존 등)에 대한 의견도 반갑습니다.
